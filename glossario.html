Glossario Tecnico

Decodifica il linguaggio dell'emulazione. Tutto quello che devi sapere, dalla A alla Z.

A B C D F I J S V

# A

API (Graphics)

Interfaccia di programmazione che permette all'emulatore di comunicare con la tua scheda video. Esempi comuni: Vulkan, DirectX, OpenGL.

# B

BIOS / Firmware

Il sistema operativo "base" della console originale. Molti emulatori (come quelli PS2 o Saturn) lo richiedono per poter avviare i giochi correttamente.

# D

Dumping

Il processo di estrazione dei dati da una cartuccia o un disco originale per trasformarlo in un file digitale (ROM o ISO) leggibile dal PC.

# J

JIT (Just-In-Time) Compilation

Una tecnica di emulazione che traduce il codice della console in codice PC "al volo". È molto più veloce dell'interpretazione pura ma richiede CPU più moderne.

# S

Shader Cache

File generati durante il gioco che memorizzano come renderizzare luci e ombre. Pre-compilarli evita gli "scatti" (stuttering) durante il gameplay.

Save State

Una funzione che permette di salvare istantaneamente in qualsiasi punto del gioco, ignorando i checkpoint originali.

# V

Vulkan

L'API grafica moderna più consigliata per l'emulazione. Offre prestazioni superiori e minor sovraccarico sulla CPU rispetto a OpenGL.
